# SmartCat

**Решение уже есть.** Сайт для распознавания школьных заданий на фото и объяснения решений.

## Как работает

- При первом открытии ученик выбирает класс с 1-го по 9-й.
- Сверху выбирает «Быстрый» или «Эксперт».
- Загружает фото или произносит задание голосом; Gemini 3.5 Flash-Lite находит отдельные задания на фото или в записи.
- Отмечает нужные задания и получает решение и ответ. В экспертном режиме их решает Gemini 3.8 Flash.
- Кнопка «Объяснение» подробнее разбирает полученное решение.
- История и счётчик пяти экспертных заданий в день хранятся локально в браузере. Фото и аудиозаписи в истории не сохраняются. Локальный лимит можно обнулить очисткой данных браузера.

## Развёртывание

Статический сайт публикуется через GitHub Pages из корня ветки `main`. Адрес Worker задаётся в `config.js`.

```bash
npm install
npx wrangler secret put GEMINI_API_KEY
npx wrangler secret put GEMINI_BACKUP_API_KEY
npm run deploy:api
```

Секреты вводятся интерактивно и никогда не помещаются в репозиторий. Для локальной разработки можно создать `.dev.vars`, который исключён из Git. Worker принимает запросы с `https://cat-yura-game.github.io`, `https://smartcat.eu.cc`, `https://www.smartcat.eu.cc` и локального адреса разработки.

## Структура

- `index.html`, `styles.css`, `app.js` — сайт без сборки.
- `assets/cat.png` — логотип SmartCat.
- `worker/index.js` — Cloudflare Worker с Gemini API.
- `wrangler.jsonc` — конфигурация Worker.

API-запросы отправляются только на Worker. Ключи Gemini доступны только ему.
